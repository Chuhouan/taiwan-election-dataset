# 臺灣選舉資料 / Election Atlas

桌面視覺原型 v3。先用兩場真實選舉打磨介面與資料表達，不擴充歷史年份。最小桌面寬度1100px。

## 範圍

- 2024總統副總統：全國、22縣市、368鄉鎮市區。
- 2024區域立法委員：73選區完整候選人及當選結果，不含原住民與不分區。
- 不收錄2020、2022等其他選舉；來源CSV仍留在原資料夾。

## 視圖與操作

- 地理圖：滾輪縮放、拖動平移、地區定位、縣市與鄉鎮圖層、離島分幅。
- 等格圖：縣市／鄉鎮等面積單元；區域立委每格為一選區一席。
- 票數氣泡：圓面積正比有效票數，位置經避讓，非精確地理位置。
- 三方圖：總統三位候選人支持率；矩形框選同步篩選地圖、列表與票數合計。
- 並列圖：總統三候選人採同投影、同得票率範圍；立委切換為73席半圓示意。
- 分布：競爭差距蜂群，或投票率與差距散點圖。
- 第一名／第二名、競爭差距、得票率及投票率；搜尋、排序、CSV匯出、最多3地區比較。
- 快捷鍵：`/`搜尋、`+` / `-`縮放、`0`全臺、`Esc`關閉面板。

## 執行與驗證

`python -m http.server 4173 --bind 127.0.0.1 --directory dist`

開啟 http://127.0.0.1:4173 。不需要API金鑰或資料庫。

`python scripts/prepare.py` 從相鄰原始資料夾重建兩場選舉資料，驗證全國票數、22縣市、鄉鎮加總與73選區。

`python scripts/verify-prototype.py` 檢查資料範圍與已儲存的瀏覽器驗證證據：框選合計及氣泡面積比例。

## 來源與限制

中選會CSV及政府開放資料：https://data.gov.tw/dataset/13119 。全國總統票數另核對 https://www.cec.gov.tw/english/article/41410 。

行政圖資為taiwan-atlas@0.0.2，內政部界線衍生資料，MIT授權見dist/vendor。固定版本僅供地理定位，不宣稱為選舉當日法定界線。立委選區邊界尚未核實，地理圖明示僅作行政區定位，使用等格、席位與列表閱讀選區結果。半圓座位不是實際座次。

D3 7.9.0、topojson-client 3.1.0及授權隨網站本地提供。採系統中文字型。

本輪研究、表達取捨與驗證見 [v3紀錄](docs/v3-visual-prototype.md)。docs內v1、v2文件為歷史紀錄，非目前資料範圍。
