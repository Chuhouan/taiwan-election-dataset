## 實測記錄

- `npm test` 的 72 項單元測試、`npm run test:data` 及構建檢查通過。桌面回歸 112 項通過，最後的路由、下鑽和地圖更新再跑 7 項通過。
- Chrome 157、Windows、i9-14900HX、本機 gzip、每組新瀏覽器環境。1024×768、1280×800、1440×900、1920×1080 首頁及圖表未有橫向溢出。另檢查了暗色地圖、詳情抽屜、雙視圖、空篩選，及 768px 恢復桌面後繪圖。首屏至縣市圖形和就緒狀態為 300–585 ms。初始 JS 177.7 KiB gzip，三個首頁 JSON 回應共 47,217 bytes。1440px 的 368 鄉鎮建圖段實測 79.4 ms。啟動仍觀察到 68–113 ms 長任務，不能宣稱達到每段低於 50 ms。
- 首頁標題、全國結果及知識卡在明暗主題下通過範圍內的 axe AA 檢查。知識卡覆蓋註冊的術語與常用指標、讀數、工具和來源。未做全站每個控件與 SVG 刻度的逐一浮層驗證。

## 本輪收尾

| 審查項 | 實作與驗收 |
| --- | --- |
| P1-01 分享狀態 | `/explore/` 的短狀態使用排序過的查詢參數，超過 8,000 個編碼字元時將完整狀態移至片段。覆蓋 368 個地區、互斥 A/B 分組及條件基底的刷新還原。根目錄舊式片段仍走舊介面，首頁章節錨點可正常定位。 |
| P0-06 首頁結論 | 以原始票數計算 158 個直轄市的區與 146 個縣轄鄉的得票率、投票率，標示未納入的 64 個行政區。2020 和 2024 全國結果依各屆分母比較，未提名不填零。 |
| P1-04、P1-05 分析台側欄 | 常用控件留在舞台，進階參數和資料表共用右側欄位。資料表首欄可帶入地圖詳情，縮放保持原比例。1024、1280、1440、1920 的側欄與散點圖各有獨立空間。 |
| P0-04、P1-07、P1-08、P1-13 說明與語言 | 刻度、圖例與常用控件使用短提示，地圖及圖點提供數值讀數，知識卡保留來源及三層導航。術語可在關於頁搜尋。抽查 33 個含 SVG 與 ARIA 的頁面元素，再用簡體切換橫軸，確認讀數與參數同步。 |
| P1-11、P1-15 動效與效能 | 關閉的表格與地區排名延後產生，切換圖表時跳過隱藏地圖的重繪。首頁與分析台轉場採用透明度，圖表切換可中斷。減少動效模式略過轉場。 |

本輪以 `npm test` 驗證 72 項單元測試，`npm run test:release` 通過 21 項發佈檢查，兩項依賴原始 CSV 的獨立來源稽核分開列計。使用系統 Chrome 對首頁比較、資料表與術語索引的明暗主題分別執行 axe WCAG AA 掃描，六組均無違規。

`npm run test:desktop -- --reporter=dot` 的 116 項回歸中，115 項通過。長連結案例初次誤用互相重疊的 A/B 資料，修正為互斥分組後已通過。最後重跑 `product-redesign.spec.js` 的 8 項驗收。

在 Windows、i9-14900HX、Chrome 157、1440×900 和本機 gzip 的新瀏覽器環境，從進入首頁到縣市圖形可見為 401 ms，368 個鄉鎮建圖段為 66.3 ms。首頁 JSON 的實際編碼回應共 47,620 bytes，分別為 `metadata.json` 4,902、`homepage.json` 3,572 及 `home-counties.json` 39,146。構建測得初始 JS 178.8 KiB gzip，CSS 另計約 30.9 kB gzip。

同組測試的首頁至分析台轉場為 432 ms，格網、氣泡、分布、三方的圖表入場為 243–246 ms。這五段動畫期間未錄得超過 50 ms 的長任務，圖表入場期間取樣的最大畫格間隔為 25 ms。開啟減少動效後沒有執行這五段轉場。數字為該測試環境的樣本，啟動與其他設備的結果另計。
