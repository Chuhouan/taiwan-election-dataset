# 历史研究剩余实施（桌面，本地；无叙事）

- 复用县市历史工作区，增加按需载入的「2014／2018／2022县市长」与「2008–2024五届立委政党票」资料；总统8届继续保留。
- 县市长只允许2014后整个县市统计单位直接对应；不将2010前县与市的不同候选人选举合成一个当选结果。2022嘉义市重行选举未含本批CSV，保留NA，不补0。
- 政党票2008前县市可依已核实的整县市改制沿革先加总票数和分母；不可与总统票或区域立委选票混用。
- 跨届政党只用明确身份的民进党／国民党；地方未提名为NA。独立候选人不冒充同一政党，不推断选民转移。
- 矩阵、双年差值、趋势共用工作区；增加擦除比较与年份滑块，限制年份为所选选举类型的真实资料。
- 历史乡镇村里与区域立委选区对应仍未经核实，保留原始结果列表和明确禁止直接比较的状态，不套用现今边界。
- 完成后复查1280／1440／1920、缺资料／未提名、跨类型路由、相机、CSV及SVG／PNG。

当前已具备：历史原始150组／37,999选区／95,139结果；全部年份可识别；总统县市8×22对账；新的公告校正保留原始标记；48项图像下载验证。主界面仍只有2024总统与立委。

11月3日完成记录：三类选票共16届，五种县市历史视图与45组桌面验收已完成；新45个实际历史下载文件通过核验。空间研究以固定共同集合与33条Rook县市边计算，21组浏览器读数经独立矩阵／999次排列检查。主界面仍只保留2024总统与立委，历史资料从独立工作区进入。
