# 桌面視覺案例與人工複核

只檢查桌面；不把行動版、額外鍵盤工作流或 Stories 納入本輪。

案例定義在 `tests/fixtures/visual-cases.js`。六類圖各有一般、單一地區、空集合、完整鄉鎮集合四類狀態；一般狀態另覆蓋 1280／1440／1920，加入雙視圖、113席及歷史矩陣。總計45個固定畫面。

初次建立：`npx playwright test tests/e2e/visual-cases.spec.js --update-snapshots --workers=2`。後續執行時不帶 update，讓快照差異報錯；不以新圖自動覆蓋舊圖。

每次改圖後，除測試幾何 NaN、水平溢出、頁面錯誤及像素差異，人工複核以下問題：

- 第一眼能辨認主要數值與資料圖形；控制區沒有壓過主圖。
- 標題、控件、圖例與資料點之間沒有非預期遮擋。
- 地名／注釋能讀，並直接連到正確點位；縮放不縮小注釋文字。
- 政黨色、連續數值、差值和透明度各自有清楚口徑。
- 氣泡面積不設虛假最小值，小單位有查詢入口；等格不暗示相同票量。
- 篩選改變統計集合；高亮／固定檢視保留集合；空集合不補成0票資料。
- 歷史缺資料／未提名／不可比不混入色階或差值。
- 圖像匯出含標題、來源、版本、圖例和必要方法說明；文字不裁切。

像素快照只保證未出現未解釋的畫面變化，不能取代上述人工判斷。基準建立當日的人工抽查記錄另寫在執行分工表，不把未看的畫面稱為已人工驗收。
