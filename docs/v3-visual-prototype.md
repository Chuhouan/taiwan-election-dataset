# v3：兩場選舉的桌面視覺原型

依使用者最新指示，只保留2024總統與2024區域立委。先驗證UI與展示，不再增加年份資料。

- [Jo Wood / UK Election 2024 Results](https://observablehq.com/@jwolondon/uk-election-2024-results)：已在瀏覽器查看等格、名次、競爭差距蜂群、票數圓、三元圖及其他表達。吸收等面積閱讀、第二名與競爭程度的分析方式。
- [Observable討論](https://talk.observablehq.com/t/mapping-the-uk-general-election/9323)：追到上述實際作品，未只以討論文字代替視覺研究。
- [Frontier選舉地圖](https://frontier-lab.io/election-map)：查看可存取的地圖、候選人與圖層控制、緊湊地區面板；進階登入功能未分析。
- [中選會2024總統視覺化](https://db.cec.gov.tw/Visual/President?dataLevel=N&legisId=00&typeId=ELC&subjectId=P0&themeId=4d83db17c1707e3defae5dc4d4e9c800)：實際進入結果面板，參考候選人概況、投票率與縣市票數／比率。
- [使用者分享內容](https://chatgpt.com/s/t_6ae778ebf7b08191959ca1679caac162)：已讀到其中的並列小地圖、三元圖與聯動框選建議。只採現有資料能支持的形式，未製作需要歷屆或個體轉投資料的流向圖。

## 本輪落地

全視窗工作區保留穩定的全國概況與左右面板，中央六種視圖共用地區選取。減少重建造成的閃爍；地圖可縮放平移，等格採連續位移，尊重減少動態效果偏好。

三方圖框選後，列表、地理圖和合計結果連動。比率以票數、投票數與選舉人數加總後計算，不平均百分比。切換地區／層級時清除框選，選取狀態可寫入URL。

總統並列小地圖同投影、同0–65%色階範圍，可切縣市範圍。區域立委使用73席示意，避免未核實的選區界線。票數氣泡以統一比例計算面積，避讓後統一縮放，未逐圓截斷半徑。
